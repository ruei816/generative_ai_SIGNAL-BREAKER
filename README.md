# SIGNAL BREAKER

**RHYTHM SIGNAL SYSTEM**

一款以賽博龐克霓虹風格為主題的節奏反應遊戲。玩家需要在訊號接近中央節拍環時，掌握正確時機進行攔截，同時避開紅色干擾訊號，並應對不同特殊訊號帶來的挑戰。
遊戲結合即時反應、節奏判定、生命值管理與動態難度調整，提供不同難度及成長策略的遊玩體驗。

---

## 遊戲畫面與特色

### 核心特色

- **節奏反應挑戰：** 觀察訊號移動位置，在適當時機點擊攔截。
- **雙難度選擇：** 提供 BEGINNER 與 ADVANCED。
- **雙成長策略：** 提供 TIME 與 ACCURACY，形成四種遊玩組合。
- **六種訊號類型：** 包含一般訊號、干擾訊號及四種特殊訊號。
- **五種點擊判定：** PERFECT、GOOD、EARLY、LATE、MISS。
- **動態難度系統：** 根據遊戲時間或近期準確率調整特殊訊號出現機率。
- **OVERDRIVE 系統：** Combo 達到指定條件後觸發分數加成。
- **遊戲統計：** 結算時顯示分數、準確率、判定次數、最高 Combo、遊戲時間與 RANK。

---

## 遊戲玩法

訊號會沿著軌道向中央節拍環移動。

玩家需要在適當的時間點擊藍色訊號及可攔截的特殊訊號，取得分數並維持 Combo。

紅色訊號屬於干擾訊號，不可點擊。誤點將受到懲罰。

### 操作方式

| 操作 | 功能 |
|---|---|
| 滑鼠左鍵 | 點擊藍色及可攔截的特殊訊號 |
| ESC | 暫停／繼續遊戲 |
| PAUSE 按鈕 | 暫停／繼續遊戲 |
| SOUND 按鈕 | 開啟／關閉音效 |

藍色訊號整顆皆可點擊，不限於中心區域。點擊空白處不會觸發判定。

## 遊戲模式

遊戲開始前可以分別選擇難度與成長策略，兩者互相獨立。

### 1. 難度選擇

| 項目 | BEGINNER | ADVANCED |
|---|---:|---:|
| 訊號移動時間 | 3200 ms | 2400 ms |
| 訊號尺寸 | 約為游標 6 倍 | 約為游標 4 倍 |
| 移動速度 | 75% | 100% |
| 分數倍率 | ×1.0 | ×1.2 |

### 2. 成長策略

| 模式 | 難度調整依據 | 說明 |
|---|---|---|
| TIME | 遊戲經過時間 | 每經過 60 秒調整一次特殊訊號機率 |
| ACCURACY | 最近 20 次有效判定的準確率 | 依玩家近期表現調整特殊訊號機率 |

兩種策略皆有 BEGINNER 與 ADVANCED 可選擇，因此共有四種組合：

- BEGINNER + TIME
- ADVANCED + TIME
- BEGINNER + ACCURACY
- ADVANCED + ACCURACY

預設組合為 **ADVANCED + TIME**。

## 訊號種類

遊戲中共有六種訊號，依照顏色區分。

| 顏色 | 訊號類型 | 效果 |
|---|---|---|
| 🔵 藍色 | NORMAL SIGNAL | 一般訊號，需在適當時機點擊 |
| 🔴 紅色 | NOISE SIGNAL | 干擾訊號，不可點擊 |
| 🟡 黃色 | BONUS | 成功攔截後，該次分數 ×2 |
| 🟢 綠色 | RECOVER | 成功攔截後回復 HP +15 |
| 🟣 紫色 | DOUBLE TAP | 必須在 650 ms 內完成兩次點擊 |
| 🟠 橘色 | FAST | 移動速度為一般訊號的 1.5 倍 |

綠色訊號回復後的 HP 不會超過 100。

黃色訊號的分數倍率可以與 OVERDRIVE 疊加。

### 紅色訊號懲罰

誤點紅色訊號時：

- 扣除 25 分（最低為 0 分）。
- 扣除 10 HP。
- Combo 歸零。
- 所有訊號、節拍與遊戲計時暫停 2 秒。

## 點擊判定系統

遊戲依照玩家點擊時間與訊號標準時機的差距，分為五種判定。

| 判定 | 時間差 | 基礎分數 | HP 影響 |
|---|---:|---:|---|
| PERFECT | ±75 ms 內 | 100 | 不扣除 |
| GOOD | 超過 ±75 ms，且在 ±170 ms 內 | 80 | 不扣除 |
| EARLY | 提前超過 170 ms，但仍成功攔截 | 50 | 不扣除 |
| LATE | 延遲超過 170 ms，但仍成功攔截 | 50 | 不扣除 |
| MISS | 未在允許判定時間內成功攔截 | 0 | -5 HP |

PERFECT、GOOD、EARLY、LATE 都屬於成功判定，可以增加 Combo。

MISS 則會扣除 5 HP，並使 Combo 歸零。

---

## ACCURACY 準確率系統

準確率用來評估玩家的攔截表現，也是遊戲結束時 RANK 評級的依據。

### 準確率計算方式

```text
Accuracy =
(PERFECT + GOOD + EARLY + LATE)
/
(PERFECT + GOOD + EARLY + LATE + MISS + 紅色誤點次數)
× 100%
```

計算規則：

- PERFECT、GOOD、EARLY、LATE：列入分子與分母。
- MISS：只列入分母。
- 紅色誤點：只列入分母。

### ACCURACY 成長策略

ACCURACY 模式採用最近 20 次有效判定的滑動視窗：

1. 累積至少 20 次有效判定後，才開始計算近期準確率。
2. 每新增 5 次有效判定，重新計算並更新難度階段。
3. 準確率依照五個區間決定特殊訊號機率。
4. 紅色誤點不列入最近 20 次有效判定，也不觸發階段更新。
5. 紫色訊號整顆只計算一次有效判定。

準確率區間：

| 區間 | 準確率 |
|---|---:|
| Stage 1 | <50% |
| Stage 2 | 50%～<60% |
| Stage 3 | 60%～<80% |
| Stage 4 | 80%～<90% |
| Stage 5 | ≥90% |

---

## RANK 評級系統

遊戲結束時，依照最終準確率給予 RANK。

| Rank | 最終準確率 |
|---|---:|
| S | ≥90% |
| A | ≥80% 且 <90% |
| B | ≥70% 且 <80% |
| C | ≥60% 且 <70% |
| F | <60% |

**RANK 完全依照最終準確率判定，不設任何分數門檻。**

遊戲分數僅作為成績展示，不影響最終 RANK。

---

## OVERDRIVE 系統

當 Combo 達到 10 時，觸發 OVERDRIVE。

| 項目 | 效果 |
|---|---|
| 觸發條件 | Combo 達到 10 |
| 持續時間 | 8 秒 |
| 分數倍率 | ×2 |
| BPM | 持續依遊戲規則提升，最高 160 |

OVERDRIVE 期間成功攔截可獲得雙倍分數。

若同時攔截黃色訊號，分數倍率可疊加至 ×4（尚未計入難度倍率）。

---

## BPM 節奏系統

遊戲會隨著遊玩時間逐漸提升節奏速度。

| 項目 | 數值 |
|---|---:|
| 初始 BPM | 100 |
| 每次增加 | +5 BPM |
| 增加間隔 | 每 12 秒 |
| 最高 BPM | 160 |

當 BPM 達到 160 後，不再繼續增加。

## 技術架構

本專案採用原生前端技術製作，不需要額外安裝框架或套件。

| 技術 | 用途 |
|---|---|
| HTML5 | 網頁結構與遊戲介面 |
| CSS3 | 霓虹視覺、動畫及響應式排版 |
| JavaScript | 遊戲邏輯、訊號生成、判定與計分 |
| Canvas API | 訊號繪製及遊戲畫面更新 |
| Web Audio API | 遊戲音效與節奏提示 |
| LocalStorage | 儲存個人最高分數 |

### 專案架構

```text
SIGNAL-BREAKER/
│
├── index.html
└── README.md
```

目前遊戲採用單一 HTML 檔案整合結構，包含 HTML、CSS 與 JavaScript。

## 如何執行

### 方法一：直接開啟

1. 下載或 Clone 專案。
2. 找到 `index.html`。
3. 使用 Chrome、Edge 或其他現代瀏覽器開啟。
4. 進入遊戲首頁即可選擇模式並開始遊玩。

### 方法二：使用 VS Code

1. 使用 VS Code 開啟專案資料夾。
2. 開啟 `index.html`。
3. 使用瀏覽器開啟該 HTML 檔案。

本專案目前不需要：

- 安裝 Node.js
- 安裝 Python
- 執行 npm install
- 設定資料庫
- 使用外部 API

## 結算統計

每次遊戲結束後，系統會顯示：

- 最終分數（SCORE）
- 最終準確率（ACCURACY）
- PERFECT 次數
- GOOD 次數
- EARLY 次數
- LATE 次數
- MISS 次數
- 最高 Combo（MAX COMBO）
- 遊戲時間（PLAY TIME）
- 紅色誤點次數（RED ERRORS）
- 個人最高分數（BEST SCORE）
- 最終 RANK

個人最高分數會儲存在瀏覽器的 LocalStorage 中。
